# Security policy

This repository is a prototype, not production software. Do not deploy it as-is.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability.

## Scope

In scope: the policy engine, the review layer, the sandbox and the audit logger.

Out of scope: the mock tools and the demo agent's model behaviour. They have no real side effects and exist only to exercise the review path.
